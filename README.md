# Theme Switcher App

This project demonstrates how to use the React Context API to manage a global light and dark theme in a React application.

## Features

* React Context API for global state management
* Light and Dark mode toggle
* Dynamic UI updates across the application
* Responsive and simple interface

## How to Run

1. Clone the repository

2. Install dependencies

npm install

3. Start the development server

npm run dev

4. Open the local URL provided by Vite in your browser

## Technologies Used

* React
* Vite
* JavaScript
* CSS
